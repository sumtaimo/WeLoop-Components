## Semantic Color Usage

| Role              | Light Source           | Dark Source            |
|-------------------|------------------------|------------------------|
| Brand primary bg  | purple/blue/orange-600 | Same family, adjusted  |
| Brand subtle bg   | purple/blue/orange-100 | Same family, 900+      |
| Default text      | neutral-950 (#000)     | neutral-50 (#FAFAFA)   |
| Subtle text       | neutral-400            | neutral-600            |
| Default border    | neutral-200            | neutral-700            |
| Danger            | red-600                | red-500                |
| Success           | green-600              | green-500              |
| Warning           | orange-600             | orange-500             |
| Info              | blue-500               | blue-400               |
| Caution           | yellow-500             | yellow-400             |
